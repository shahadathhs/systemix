# Security policy

## Reporting a vulnerability

Please report security problems privately through
[GitHub private vulnerability reporting](https://github.com/shahadathhs/systemix/security/advisories/new).
Do not open a public issue.

Include the package and version, your Node.js version, a short reproduction and
what an attacker gains. Systemix has one maintainer, so there is no guaranteed
response time.

## Supported versions

Fixes land on `main` and ship as a new release; older versions are not patched
separately. Node.js 24.7 or newer is required.

For versioning, release provenance and known limits, see the
[security and support page](https://systemix.vercel.app/docs/security).
